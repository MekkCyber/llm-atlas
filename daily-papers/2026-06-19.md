## 1. UFP4

**Authors:** Kunlong Chen, Changxin Tian, Zhonghui Jiang, Haitao Zhang, Chaofan Yu, Peijie Jiang, Mingliang Gong, Jia Liu, Ziqi Liu, Zhiqiang Zhang, Jun Zhou — *Ant Group*
**Links:** [arXiv:2606.20381](https://arxiv.org/abs/2606.20381) · [HF](https://huggingface.co/papers/2606.20381) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.20381)
**Topics:** `quantization`, `pre-training`, `MoE`

### TL;DR

A pretraining-quality argument against the E2M1 FP4 element format used by Blackwell/Rubin/MI350. The authors show that E2M1's asymmetric bins produce a systematic negative rounding error ("Shrinkage Bias") that compounds layer-by-layer and is amplified by Random Hadamard Transforms. Their fix — UFP4 — swaps E2M1 for uniform 4-bit grids (E1M2 / INT4) and restricts stochastic rounding to the dY GEMM only.

### Key idea

Element-format *geometry* matters as much as scale granularity. Non-uniform FP4 grids (E2M1) place more representable values near zero, so the round-to-nearest expectation is biased downward; this bias multiplies across layers. Uniform grids (E1M2 / INT4) have symmetric bins → unbiased rounding → RHT actually delivers its promised SQNR gain.

### Main finding

On Dense 1.5B, MoE 7.9B, and MoE 124B long-run pretraining, UFP4 yields lower BF16-relative loss degradation than every E2M1 baseline. Scaling-law fits and ablations isolate the contribution of element geometry vs. RHT vs. stochastic rounding placement.

### Why it matters

If the pretraining community agrees with this analysis, the next generation of FP4 hardware needs first-class E1M2 / INT4 paths instead of E2M1-only tensor cores. That's a concrete recommendation to NVIDIA / AMD silicon roadmaps and a warning to teams currently committing to E2M1 recipes for frontier-scale pretraining.

## 2. Taylor-Calibrate

**Authors:** Zhongzhu Zhou, Qingyang Wu, Junxiong Wang, Mayank Mishra, Shuaiwen Leon Song, Ben Athiwaratkun, Chenfeng Xu — *Together AI / U. Sydney / Berkeley / UT Austin / Microsoft*
**Links:** [arXiv:2606.16429](https://arxiv.org/abs/2606.16429) · [HF](https://huggingface.co/papers/2606.16429) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.16429)
**Topics:** `architectures`, `efficient-inference`, `distillation`

### TL;DR

Converting a pretrained softmax-attention Transformer into a hybrid Gated DeltaNet (GDN) student is brittle: just copying the attention projections leaves the recurrent decay, write gate, and output gate uninitialized, so the student spends most of distillation undoing a bad starting point. Taylor-Calibrate uses a Taylor expansion of the teacher's attention to set those GDN-specific knobs, then runs a short per-layer alignment pass.

### Key idea

Treat the GDN student's recurrent state-update as a Taylor approximation to the teacher's softmax attention around the current token, then read off the values for the new parameters (value projection, memory timescale, write/output gates) so that the converted layer matches the teacher's output to first order *before* distillation starts.

### Main finding

Up to **88× better zero-shot students** in a representative ablation, and **4.9× – 9.2× fewer distillation tokens** to reach matched recovery targets across four teacher settings and three retained-layer policies. The gain is purely from initialization — no architectural change to GDN.

### Why it matters

Linear-attention distillation is the practical route to long-context inference on commodity hardware. Today every team rolls their own initialization heuristics. A principled, cheap calibration step that cuts distillation cost by ~5× makes hybrid linear-attention conversion a default optimization rather than a research project.

## 3. FAPO

**Authors:** Baturay Saglam, Huaibo Zhao, Blaine Nelson, Supriti Vijay, Aman Priyanshu, Amin Karbasi — *Cisco Foundation AI / Yale*
**Links:** [arXiv:2606.19605](https://arxiv.org/abs/2606.19605) · [HF](https://huggingface.co/papers/2606.19605) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.19605)
**Topics:** `agents`, `LLM-pipelines`

### TL;DR

A meta-agent (Claude Code, sandboxed in a standardised pipeline codebase) that optimizes another LLM pipeline against a score function. It first tries prompt edits; only when attribution shows a structural bottleneck does it modify the pipeline's chain structure within an allowed scope.

### Key idea

Treat prompt optimization as a coding agent task with a fixed evaluation harness. The optimizer inspects intermediate steps, runs counterfactuals, and proposes scoped changes, escalating from prompt-only edits to structural changes only when attribution justifies it. Prompts are *not* the only knob — pipeline topology is too.

### Main finding

End-to-end autonomous improvement of multi-step pipelines without per-task manual prompt engineering. (Quantitative gains: paper-only; the abstract lists the framework rather than specific numbers.)

### Why it matters

Most "automatic prompt optimization" work assumes the pipeline is fixed and only the prompts vary. Real production pipelines fail because of bad chain structure as often as bad prompts. FAPO is one of the first explicit demonstrations of an agent that *modifies pipeline structure* under a guardrail, which is the natural endgame for self-improving LLM systems.

### Knowledge graph integration

**Suggested new pages:**
- `agents/automated-prompt-optimization.md` *(depth)* — agent-driven prompt + structure optimization, FAPO/DSPy-class systems.

## 4. S-Agent

**Authors:** Yalun Dai, Hao Li, Shulin Tian, Runmao Yao, Yuhao Dong, Fangzhou Hong, Zhaoxi Chen, Fangfu Liu, Baoliang Tian, Dingwen Zhang, Tao Wang, Kim-Hui Yap, Ziwei Liu — *NTU / Tsinghua / ByteDance / NWPU*
**Links:** [arXiv:2606.20515](https://arxiv.org/abs/2606.20515) · [HF](https://huggingface.co/papers/2606.20515) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.20515)
**Topics:** `agents`, `multimodal`, `reasoning`

### TL;DR

S-Agent uses a VLM as a planner that decides *what 3D evidence is needed*, then delegates to a hierarchy of spatial tools (2D grounding, lift-to-3D, geometric reasoning) and aggregates the results into spatial knowledge. A temporal memory persists state across observations so the agent reasons over an evolving 3D scene rather than isolated frames.

### Key idea

Spatial intelligence ≠ better VLM weights. Treat it as a tool-use problem: the VLM plans, specialist 3D tools execute, and a temporal memory closes the loop across observations. Reasoning is offloaded from the VLM's weights into the tool-call graph.

### Main finding

Consistent improvements over baseline VLMs on multiple spatial benchmarks, both zero-shot and when fine-tuned as **S-Agent-8B**. (Exact deltas paper-only.)

### Why it matters

Lifts the spatial-reasoning bottleneck off model size. Frontier VLMs still confuse left/right and miss distance; if a tool-use scaffold around a mid-size VLM beats them, the right axis to scale is *grounding tools*, not parameters. Same playbook GPT-4o-style "think with images" papers are converging on.

### Knowledge graph integration

**Suggested new pages:**
- `agents/spatial-tool-use.md` *(depth)* — the planner + 3D-tool hierarchy + temporal memory pattern.
- `multimodal/spatial-reasoning-benchmarks.md` *(taxonomy)* — placeholder for the growing class of 3D-aware VLM evaluations.

## 5. LedgerAgent

**Authors:** Md Nayem Uddin, Amir Saeidi, Eduardo Blanco, Chitta Baral — *Arizona State / U. Arizona*
**Links:** [arXiv:2606.20529](https://arxiv.org/abs/2606.20529) · [HF](https://huggingface.co/papers/2606.20529) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.20529)
**Topics:** `agents`

### TL;DR

Tool-calling agents fail customer-service policies because task state is left implicit in the prompt — they reconstruct it from chat history every turn and ground decisions in stale facts. LedgerAgent maintains an explicit **ledger** of observed facts, identifiers, constraints, and conditions, renders it into the prompt every turn, and uses it as a precondition check before any environment-changing tool call.

### Key idea

Separate the agent's *belief state* from its *prompt context*. The ledger is the single source of truth for "what does the agent currently know?" — updated by observations and tool returns, consulted by both reasoning and policy enforcement.

### Main finding

Across four customer-service domains and a panel of open and closed models, LedgerAgent improves average **pass^k** (multi-trial consistency) over standard prompt-based tool-calling, with the **largest gains at stricter k** — i.e. the failure mode it fixes is variance, not peak performance.

### Why it matters

The pass^k gap is the metric production agent teams actually care about: customer-service agents must succeed every time, not just sometimes. An inference-time scaffold that closes that variance gap without re-training is immediately useful, and the "ledger as policy-enforcement substrate" idea generalizes to any compliance-heavy agent setting.

### Knowledge graph integration

**Suggested new pages:**
- `agents/structured-state-agents.md` *(depth)* — the ledger pattern, policy preconditions, and the pass^k variance argument.

## 6. Multi-LCB

LiveCodeBench, but in twelve programming languages. Same contamination-aware rolling release, same hidden-test grading — just no longer Python-only. Lets papers compare reasoning models' multilingual code generalization head-to-head.

Benchmark introduction paper — exact rankings are paper-only, but the headline question is whether SOTA reasoning models trained mostly on Python code generalize to Go / Rust / etc.

### Why it matters

LCB has become the default "post-cutoff code reasoning" eval, and its Python-only scope is a known weakness. Multi-LCB closes that hole and is likely to become the standard multilingual code benchmark cited in 2026 model releases.

## 7. Beyond Static Leaderboards

**Authors:** Dhaval C. Patel et al. (~60 co-authors) — *IBM*
**Links:** [arXiv:2606.19704](https://arxiv.org/abs/2606.19704) · [HF](https://huggingface.co/papers/2606.19704) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.19704)
**Topics:** `eval`, `agents`

### TL;DR

Position paper aggregating 14 parallel studies on one MCP-based agent benchmark plus 7 prior benchmarks. Argues that aggregate-score leaderboards systematically underspecify deployed-agent quality: in-sample rank does not transfer to out-of-distribution settings. Proposes ranking by **predictive validity** — the correlation between in-sample and out-of-sample rank — and lays out a 12-tier measurement apparatus.

### Key idea

Rank stability *across* distributions is the metric, not mean score within one distribution. Three falsifiable OOD criteria are proposed with explicit thresholds, with a pre-registered pilot to test them.

### Main finding

Public-to-hidden competition retrospectives provide direct empirical evidence of rank instability in agent leaderboards. No single existing benchmark covers more than ~4–5 deployment-relevant dimensions.

### Why it matters

Agentic evaluation is at the same crisis point image classification benchmarks hit in 2019. If predictive-validity-style metrics take hold, the next round of agent benchmarks would look very different — multi-scenario, OOD-by-design, with pre-registered evaluation protocols. Relevant to anyone deciding which agent eval to trust.

### Knowledge graph integration

**Suggested new pages:**
- `evaluation/predictive-validity.md` *(depth)* — rank-stability metric for agent leaderboards, OOD criteria framework.
- `evaluation/_agent-benchmarks.md` *(taxonomy)* — placeholder for the agent-eval landscape (SWE-bench, WebArena, GAIA, MCP-bench, BrowseComp, …).

## 8. FID Lottery

**Authors:** Nicolas Dufour, Alexei A. Efros, Patrick Pérez — *Kyutai / UC Berkeley*
**Links:** [arXiv:2606.20536](https://arxiv.org/abs/2606.20536) · [HF](https://huggingface.co/papers/2606.20536) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.20536)
**Topics:** `eval`, `diffusion`

### TL;DR

Treats FID as a random variable across training seeds and sampling seeds. Trains *several hundred* SiT networks on ImageNet 256² and measures the spread. Result: **retraining moves FID 3.2× more than resampling**, the spread doesn't shrink with scale, and per-cell CFG tuning halves variance but reshuffles which seeds win.

### Key idea

Two-axis seed panel (training × generation). Decompose FID variance into init / data ordering / per-step flow-matching noise. Quantify how much of any reported FID delta is signal vs. seed lottery.

### Main finding

Lucky training seeds reach the same FID as unlucky ones with **up to 2× less compute**. The FID coefficient of variation stays inside a 1–2% band regardless of compute or model size. Per-cell CFG tuning halves the spread.

### Why it matters

Single-seed FID comparisons are the standard in diffusion / flow papers and are routinely below the seed-noise floor for the deltas they claim. This paper gives concrete numbers for what counts as a real improvement — required reading for any future generative-model evaluation, and a template for similar analyses of LLM benchmarks.

### Knowledge graph integration

**Suggested new pages:**
- `evaluation/fid-variance.md` *(depth)* — generative-model evaluation under seed noise; the two-axis variance decomposition.

## 9. ImageWAM

**Authors:** Authors not individually listed on HF page — *Shanghai Jiao Tong / Eastern Institute of Technology / Tencent Robotics X / Tsinghua / Zhongguancun Academy*
**Links:** [arXiv:2606.19531](https://arxiv.org/abs/2606.19531) · [HF](https://huggingface.co/papers/2606.19531) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.19531)
**Topics:** `multimodal`, `agents`, `efficient-inference`

*Borderline: included because the "image-editing replaces video generation" insight is broadly applicable to multimodal/agent world models, not robotics-only.*

### TL;DR

World Action Models (WAMs) usually predict future video frames to learn control. ImageWAM argues video is wasted capacity: most action-relevant change is local image editing. Repurposes a pretrained image-editing model as the WAM backbone, drops the temporal axis, and gets cheaper inference with no quality loss.

### Key idea

The "imagined next state" only needs to capture the diff between current observation and goal — that's an *image-editing* problem, not a *video-generation* one. Sidesteps dense multi-frame tokens, action-irrelevant temporal/appearance detail, and long-horizon error accumulation.

### Main finding

Cheaper inference and comparable / better action prediction vs. video-based WAM baselines. (Exact numbers paper-only.)

### Why it matters

The robot-foundation-model wave (RT-2, OpenVLA, π-0, …) defaults to video prediction. A serious "do you actually need video?" challenge — if it holds up at scale — would re-shape the WAM stack and free up GPU budget for the policy head.

### Knowledge graph integration

**Suggested new pages:**
- `multimodal/world-action-models.md` *(depth)* — WAM definition, video-vs-image variants, control-relevance argument.

## 10. WRBench

**Authors:** Jinpeng Lu, Dexu Zhu, Haoyuan Shi, Linghan Cai, Guo Tang, Yinda Chen, Jie Cao, Duyu Tang, Yi Zhang, Yong Dai, Xiaozhu Ju — *USTC / X-Humanoid / NLPR-CAS / TU Dresden / Peking U.*
**Links:** [arXiv:2606.20545](https://arxiv.org/abs/2606.20545) · [HF](https://huggingface.co/papers/2606.20545) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.20545)
**Topics:** `eval`, `diffusion`, `multimodal`

### TL;DR

A benchmark plus position paper testing whether modern "world models" actually maintain *persistent state*. Most current systems generate realistic frames but lose track of object state when the camera moves away and returns. WRBench measures **state attribution under camera-induced observability changes** — and current SOTA video world models fail.

### Key idea

A world model must have a state core that survives occlusion, not just a frame predictor. Test design: scenes where a dynamic event happens off-screen and the model must produce frames consistent with what happened while not observed.

### Main finding

Current video / world-model SOTA produces visually plausible but **state-inconsistent** continuations. The gap between "looks right" and "remembers right" is large and largely unmeasured.

### Why it matters

World-model claims (Sora-class, Genie-class) are currently graded on perceptual quality. WRBench shifts the goalposts to representational persistence — much closer to what "world model" means in the AGI sense the authors invoke. If adopted, it would invalidate a chunk of recent video-world-model claims.

### Knowledge graph integration

**Suggested new pages:**
- `evaluation/wrbench.md` *(depth)* — persistent-state attribution benchmark for video world models.

## 11. FlowBender

**Authors:** Daniel Gilo, Sven Elflein, Ido Sobol, Or Litany — *Technion / NVIDIA / U. Toronto / Vector Institute*
**Links:** [arXiv:2606.20404](https://arxiv.org/abs/2606.20404) · [HF](https://huggingface.co/papers/2606.20404) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.20404)
**Topics:** `diffusion`, `flow-matching`

### TL;DR

Conditional diffusion / flow models routinely violate the very constraints that define their task (a depth-conditioned model produces images whose re-extracted depth disagrees with the input). FlowBender trains the model to consume its *own* alignment error as a first-class input, learning a correction policy conditioned on inference-time feedback.

### Key idea

Close the loop at *training* time, not just inference. Each step: (1) unguided look-ahead → estimate clean sample, (2) compute task-specific deviation via the forward operator, (3) refinement pass uses that deviation to produce a corrected velocity. Gradient-based for differentiable operators, zero-order for non-differentiable ones (e.g. JPEG).

### Main finding

Across image-to-image translation, restoration, and 3D mesh texturing, FlowBender beats supervised baselines, alignment-loss-augmented training, and SOTA inference-time guidance — improving fidelity *and* plausibility simultaneously rather than trading them off.

### Why it matters

Inference-time guidance is the standard fix for conditional-flow misalignment; it requires hand-tuned linear updates and trades fidelity vs. plausibility. Training-time feedback-aware models could obsolete guidance for any task with an available forward operator (which is most controllable generation tasks).

### Knowledge graph integration

## 12. Visually Grounded Thinking

**Authors:** Junkai Zhang, Yihe Deng, Kai-Wei Chang, Wei Wang — *UCLA*
**Links:** [arXiv:2606.16122](https://arxiv.org/abs/2606.16122) · [HF](https://huggingface.co/papers/2606.16122) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.16122)
**Topics:** `multimodal`, `RL`, `reasoning`

### TL;DR

VLMs that "think" in natural language leave their visual evidence implicit and unverifiable. The authors interleave reasoning text with explicit point / box groundings of every visual referent, train via a synthesis pipeline using SAM3 to extract grounded objects, and add **grounding-aware RL** — answer-correctness reward plus dense grounding rewards.

### Key idea

Make the intermediate trace a *verifiable evidence chain*: every object the trace mentions must be tied to an image region. Grounding rewards can be applied densely (per step) on top of answer correctness, giving the RL signal much higher density than answer-only RL.

### Main finding

On two counting and four spatial-reasoning benchmarks, visually grounded thinking added to **Gemma3-4B-IT** matches or surpasses **Gemma3-27B-IT** on spatial reasoning. Point grounding wins for counting; box grounding benefits more from explicit grounding rewards.

### Why it matters

Two directions: (1) a 4B model beating a 27B sibling via better RL signal density says spatial reasoning is bottlenecked by *supervision shape*, not parameter count; (2) the grounding-as-RL-reward pattern transfers — anything with a verifiable intermediate annotation (code AST, math sub-step) is now a candidate for dense process rewards.

## 13. ContextRL

**Authors:** Peiyang Xu, Bangzheng Li, Sijia Liu, Karthik R. Narasimhan, Pramod Viswanath, Prateek Mittal, Xingyu Fu — *Princeton / UC Davis*
**Links:** [arXiv:2606.17053](https://arxiv.org/abs/2606.17053) · [HF](https://huggingface.co/papers/2606.17053) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.17053)
**Topics:** `RL`, `agents`, `multimodal`

### TL;DR

LLMs fail when answering needs one decisive piece of evidence inside a long tool trace or subtle image detail. ContextRL adds an indirect auxiliary RL objective: present the model with a query, an answer, and *two highly similar contexts*, and reward it for picking the one that actually supports the QA pair. Forces fine-grained grounding without supervising final answers alone.

### Key idea

Use *contrastive context selection* as an auxiliary RL reward. The model never sees explicit "highlight the relevant line" supervision — but to pick the right context out of two near-duplicates, it must internally locate the decisive evidence.

### Main finding

Improves long-horizon reasoning and multimodal QA on tasks where the answer depends on a small region of the context. (Specific deltas paper-only.)

### Why it matters

A general recipe for cheap, scalable "attention-shaping" RL: easy to construct near-duplicate contexts from synthetic perturbations, no human labels required, plays nicely on top of GRPO / RLVR. Especially relevant for agentic LLMs reasoning over long tool traces, the failure mode this directly addresses.

- [rlvr.md](../post-training/rlvr.md) — same family (verifiable auxiliary signal), different verifier.

## 14. Moebius

**Authors:** Anonymous student team — *VIVO AI Lab / Huazhong U. of Science & Tech (corr. Xinggang Wang)*
**Links:** [arXiv:2606.19195](https://arxiv.org/abs/2606.19195) · [HF](https://huggingface.co/papers/2606.19195) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.19195)
**Topics:** `diffusion`, `efficient-inference`, `distillation`

### TL;DR

A 0.22B inpainting model that matches FLUX.1-Fill-Dev (11.9B) on natural and portrait benchmarks. The architecture replaces standard attention blocks with **Local-λ Mix Interaction (LλMI)** blocks that summarise spatial context and global priors into fixed-size linear matrices; the recipe pairs this with adaptive multi-granularity latent-space distillation.

### Key idea

Two-part: (1) **LλMI block** — Local-λ and Interactive-λ modules compress spatial + semantic info into fixed-size linear operators, drastically cutting parameters while preserving latent interactions; (2) **multi-granularity latent distillation** that balances multiple gradient-based losses dynamically, all inside the latent space.

### Main finding

**<2% of FLUX.1-Fill-Dev's parameters** (0.22B vs 11.9B) with **>15× inference-time acceleration**, rivalling or surpassing FLUX-level inpainting quality on the paper's benchmarks.

### Why it matters

The dominant diffusion-compression narrative has been quantization + LoRA. A genuine architecture-level compression that holds quality at 50× smaller parameter count moves the conversation back to architecture, and points at LλMI-style linear-summary blocks as a general tool for compressing big diffusion backbones.

### Knowledge graph integration

## 15. FreeStyle

**Authors:** Jinghong Lan, Wei Cheng, Yunuo Chen, Ziqi Ye, Peng Xing, Yixiao Fang, Rui Wang, Yufeng Yang, Xuanyang Zhang, Xianfang Zeng, Difan Zou, Gang Yu, Chi Zhang — *Fudan University*
**Links:** [arXiv:2606.20506](https://arxiv.org/abs/2606.20506) · [HF](https://huggingface.co/papers/2606.20506) · [AlphaXiv](https://www.alphaxiv.org/abs/2606.20506)
**Topics:** `diffusion`, `LoRA`, `data`

### TL;DR

A scalable framework for style-content dual-reference image generation. Mines existing community LoRAs to synthesize large-scale style-content triplets, then trains a disentangled model that addresses the perennial **content-leakage** failure mode (style refs bleeding their semantics into the output).

### Key idea

Use *the community LoRA ecosystem itself as a training-data source*. Each LoRA encodes a style; sampling from it gives synthetic style-content pairs at scale, sidestepping the licensing and labelling cost of curating real triplets. Add a disentanglement mechanism explicitly targeting content leakage.

### Main finding

Better balance between content fidelity, style alignment, and instruction following on the paper's dual-reference benchmark, with the largest gains in resistance to style-reference content leakage.

### Why it matters

The "community LoRAs as data" recipe is the interesting bit. As open LoRA libraries grow (CivitAI etc.), they form a *de facto* style corpus that is much richer than any single hand-curated dataset. The same idea generalises beyond style transfer — domain LoRAs as a synthetic-data source for any domain.
