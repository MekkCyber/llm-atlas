## 1. From Pixels to States

**Authors:** Zian Meng, Shuwei Shi, Mingliang Zhai, Jiaming Tan, Chuanhao Li, Kaipeng Zhang — *Alaya Lab*
**Links:** [arXiv:2607.14076](https://arxiv.org/abs/2607.14076) · [HF](https://huggingface.co/papers/2607.14076) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.14076)
**Topics:** `world-models`, `multimodal`, `diffusion`

### TL;DR

A survey + resource paper that reframes generative video world models as **interactive game engines**. The authors argue the field should be organized around the classical game-engine loop (action → state → observation) and evaluate progress along four dimensions: player action control, state dynamics, state-observation persistence, and real-time generation. They also release a 90-hour Black Myth: Wukong dataset with frame-aligned actions, ground-truth game states, and structured/semantic annotations to enable *state-aware* training.

### Key idea

Explicit **game state** as the missing scaffolding of neural world models. Pure pixel-prediction models lose track of rules and consequences over long horizons because they never materialize state — the paper's taxonomy groups approaches by *how much of the classical action-state-observation loop each family reproduces*. The dataset gives ground-truth `(action, state, pixels)` triples so future models can be trained to predict, or condition on, explicit state.

### Main finding

This is a position + resource paper — no single new benchmark score. The concrete deliverable is the taxonomy, the "four-dimension" evaluation lens, and 90 hours of AAA-quality gameplay with frame-aligned state.

### Why it matters

Neural game engines (Genie, Oasis, GameNGen…) have exploded in visual fidelity but still fail at rule persistence — this paper sharpens the vocabulary for *what's actually missing* and provides a dataset that makes state-conditioned training tractable. Expect a wave of "state-aware" world model variants using the same framing.

## 2. LongStraw

**Authors:** Changhai Zhou, Kieran Liu, Yuhua Zhou, Qian Qiao, Jun Gao, Harry Zhang, et al. — *Cross-affiliation consortium*
**Links:** [arXiv:2607.14952](https://arxiv.org/abs/2607.14952) · [HF](https://huggingface.co/papers/2607.14952) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.14952)
**Topics:** `RL`, `systems`, `long-context`

### TL;DR

An architecture-aware execution stack for **million-token GRPO** under a fixed GPU budget. Post-training RL is stuck at ≤256K contexts while inference stretches to millions — LongStraw closes the gap by evaluating the shared prompt without autograd, keeping only the model-specific state later tokens need, and replaying short response branches one at a time. Trades wall-clock for memory linearity in the group dimension.

### Key idea

Split a GRPO step into a **detached prompt forward** (no autograd, checkpointed model state) plus **per-response replay** of the short response branches. Because only the response is differentiable and the shared prompt state is cached in an architecture-aware way (recurrent for hybrid attention, compressed for MoE), memory grows almost independently of group size.

### Main finding

On 8×H20, LongStraw scores 2.1M-token groups of size 2 and 8 for hybrid-attention Qwen3.6-27B; enlarging the group adds only **+0.21 GB peak**. A separate stress test reaches **4.46M positions**. On 32×H20, the pipeline runs end-to-end for a 2.1M-token prompt across all 78 layers of MoE GLM-5.2. Correctness of distributed gradient composition is not yet fully verified — this is an execution-capacity paper.

### Why it matters

If agentic RL needs prompts as long as the deployed context (tool histories, evidence graphs), post-training has to keep up. LongStraw is the first published recipe I've seen that plausibly stretches GRPO to genuinely million-token regimes without linear memory blowup per group.

## 4. SEED

**Authors:** Jinyang Wu, Shuo Yang, Zhengxi Lu, Fan Zhang, Yuhao Shen, Lang Feng, et al. — *Tsinghua / Zhejiang / CUHK / NTU / Tongji*
**Links:** [arXiv:2607.14777](https://arxiv.org/abs/2607.14777) · [HF](https://huggingface.co/papers/2607.14777) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.14777)
**Topics:** `agents`, `RL`, `distillation`

### TL;DR

Attacks the **sparse-reward problem in agentic RL** — outcome-based rewards give zero signal on intermediate decisions in a long trajectory. SEED converts completed trajectories into "hindsight skills" and distills those behavioral effects back into the policy, filling the supervision gap between episode-level outcomes and token-level policy updates.

### Key idea

**Hindsight skill extraction + self-distillation.** From a completed trajectory (success or failure), factor out reusable skill fragments and use them as dense supervision during the next RL step. Behavior distilled from the agent's own past traces means no teacher model is needed — the recipe is "self-evolving." Related to hindsight experience replay but with skills instead of goal-relabeling.

### Main finding

Outperforms outcome-only RL baselines on long-horizon multi-turn agent tasks (specific benchmarks not enumerated in the abstract fragment).

### Why it matters

Agentic RL desperately needs credit assignment across long trajectories. Self-distilled skills sidestep the need for a step-level reward model or a strong teacher — an important recipe for scaling agent post-training without frontier judges.

## 5. SearchOS-V1

**Authors:** Junjie Gao, Zhengxian Wu, Jiaming Fan, Jin Zhang, Shihan Ma, Yao Yao, Weiran Qi, Chuyan Jin, Guiyu Ma, Xingzhong Xu, Kai Yang, Ji-Rong Wen, Zhicheng Dou — *Renmin University of China / Ant Group*
**Links:** [arXiv:2607.15257](https://arxiv.org/abs/2607.15257) · [HF](https://huggingface.co/papers/2607.15257) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.15257)
**Topics:** `agents`, `RAG`, `systems`

### TL;DR

A system-level multi-agent framework for **open-domain information-seeking** that externalizes the previously implicit agent search state. Turns search into "relational schema completion with grounded citations": agents discover entities, populate attributes across linked tables, and anchor each value to source evidence. A middleware harness records grounded evidence and reacts to stalls or budget exhaustion.

### Key idea

**Search-Oriented Context Management (SOCM)** — four externalized state objects (Frontier Task, Evidence Graph, Coverage Map, Failure Memory) let multiple sub-agents share progress and avoid the repetitive-loop failure mode. Pipeline-parallel scheduling continuously refills slots with tasks targeting *unresolved coverage gaps*. A tool middleware layer catches stalls before they eat the budget.

### Main finding

Beats all evaluated single- and multi-agent baselines on WideSearch and GISA across every reported metric.

### Why it matters

The recurring failure of RAG agents is loop-forever-on-bad-query. Making the search state explicit and shared (with a Failure Memory) is the right architectural fix, and it's the shape most production RAG-agent stacks are converging to.

## 7. Spectral Rewiring (SAR)

**Authors:** Hongli Yu, Huan-ang Gao, Hanlin Wu, Yuxuan Song, Wei-Ying Ma, Ya-Qin Zhang, Hao Zhou — *SIA-Lab of Tsinghua AIR & ByteDance Seed*
**Links:** [arXiv:2607.03065](https://arxiv.org/abs/2607.03065) · [HF](https://huggingface.co/papers/2607.03065) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.03065)
**Topics:** `RL`, `merging`, `post-training`

### TL;DR

Argues the **reasoning-effective component of RL post-training updates lives in a low-rank spectral subspace of the base model**. Subspace-Aligned Rewiring (SAR) is a training-free, post-hoc edit that retains the aligned spectral core and discards orthogonal update components — killing test-time-scaling saturation and cross-domain interference in one move.

### Key idea

Project the post-training delta `ΔW = W_rlhf − W_base` onto the base model's dominant singular directions and keep only that projection. As little as **~0.58% of parameters** captures the "reasoning-effective" slice; the rest is noise or interference. Also enables clean model merging: project each expert's delta onto its shared base and add.

### Main finding

Keeping ~0.58% of parameters **preserves >99% of post-training performance**, improves high-k exploration in math, generalizes to agentic coding (better on 6 of 7 open benchmarks), releases suppressed coding capability without harming math, and beats existing model-merging baselines and even the best single-domain experts.

### Why it matters

Model merging has been mostly hand-tuned heuristics. If updates factor cleanly along the base's spectral geometry, both "compact reasoning cores" and principled multi-expert merging become training-free operations — a big deal for open-weights consolidation.

## 8. Demystifying On-Policy Distillation

**Authors:** *Not disclosed in HF metadata*
**Links:** [arXiv:2607.13399](https://arxiv.org/abs/2607.13399) · [HF](https://huggingface.co/papers/2607.13399) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.13399)
**Topics:** `distillation`, `RL`, `post-training`

### TL;DR

A systematic study of what **on-policy distillation (OPD)** actually does. Casts OPD as an *exploration catalyst* rather than a capability booster: dense token-level guidance steers the student to correct reasoning paths but does not raise the capability ceiling. Identifies two pathologies (student-teacher mismatch, length exploitation) and proposes lightweight fixes.

### Key idea

**OPD ≠ capability transfer** — its job is to shape which correct paths the student explores. The paper isolates two failure modes: (i) *Student-Teacher Mismatch* — a distributional gap between teacher and student makes the guiding signal misaligned; (ii) *Length Exploitation* — the aggregated token-level objective is length-dependent, so the student games it via truncation or padding. Fixes are surgical: **advantage clipping** and **log-scale compression** of the signal.

### Main finding

Across seven benchmarks, the regulated variants **eliminate length exploitation** and **stably surpass naïve OPD and RLVR**. Prompt diversity matters more than per-problem sampling count; effectiveness depends on guiding-signal quality, not teacher scale.

### Why it matters

OPD is spreading through post-training pipelines (Kimi, DeepSeek-R1 successors) but the "when does this actually help?" story has been thin. This paper is likely to become the reference explaining OPD's role — and the reg tricks are essentially free wins.

## 9. DeepLoop

**Authors:** Shuzhen Li, Yifan Zhang, Jiacheng Guo, Quanquan Gu, Mengdi Wang — *Princeton / University of California*
**Links:** [arXiv:2607.13491](https://arxiv.org/abs/2607.13491) · [HF](https://huggingface.co/papers/2607.13491) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.13491)
**Topics:** `architectures`, `pre-training`, `stability`

### TL;DR

Looped transformers (a compact stack applied for N rounds) increase effective depth **without** more parameters, but the classical DeepNorm residual scaling breaks under weight tying. DeepLoop derives the corrected scaling — α=(2N)^{1/2}, β=(8N)^{-1/2} for unrolled depth N — from a first-order perturbation bound and a *visit-alignment coefficient* κ_R.

### Key idea

In an untied network each residual branch owns its own parameters, but in a **looped** network one shared parameter aggregates gradients from all its visits and is read back next pass. The bound reveals that in the aligned regime, the DeepNorm exponent must increase from **1/4 to 1/2** as loop count rises. Fix the exponent, and the Post-LN DeepNorm architecture becomes stable at arbitrary loop count.

### Main finding

On GPT-2-small / medium scale looped models, DeepLoop is neutral when nothing is revisited and *improves validation loss + downstream accuracy* once recurrent depth is activated. Stability now scales with loop count, not just physical depth.

### Why it matters

Looped/weight-tied architectures are the natural way to trade compute for parameters — critical for on-device inference or very deep effective networks. Getting the scaling right is a prerequisite for using them at frontier scale.

## 10. MeanFlowNFT

**Authors:** Yushi Huang, Xiangxin Zhou, Jun Zhang, Liefeng Bo, Tianyu Pang — *Tencent Hunyuan / HKUST*
**Links:** [arXiv:2607.15273](https://arxiv.org/abs/2607.15273) · [HF](https://huggingface.co/papers/2607.15273) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.15273)
**Topics:** `diffusion`, `RL`, `flow-matching`

### TL;DR

Adapts **forward-process RL (DiffusionNFT)** — which needs no reverse trajectories or likelihood estimation — to **MeanFlow** generators, which sample fast few-step by predicting *average* velocities. Bridges instantaneous-vs-average velocity via the MeanFlow identity, keeps MeanFlow's fast sampling, inherits DiffusionNFT's strict policy-improvement guarantee.

### Key idea

DiffusionNFT optimizes an *instantaneous-velocity* predictor. MeanFlow uses *average* velocities. MeanFlowNFT builds an **induced instantaneous-velocity predictor** from the MeanFlow identity, runs the DiffusionNFT objective on that induced predictor, and samples from the original MeanFlow. Reward-shaping fine-tuning now composes cleanly with few-step diffusion.

### Main finding

Consistent improvements over MeanFlow baselines on image and video generation with preserved few-step sampling speed. Formal proof of monotonic policy improvement carried over from DiffusionNFT.

### Why it matters

Few-step generators (MeanFlow, Consistency Models) are the deployment target; forward-process RL (no likelihood, no reverse rollouts) is the cheapest way to align them. This unlocks reward-driven fine-tuning of the fastest diffusion samplers.

## 11. Byte-Exact KV-State Grafting

**Authors:** Sietse Schelpe — *Independent*
**Links:** [arXiv:2607.14431](https://arxiv.org/abs/2607.14431) · [HF](https://huggingface.co/papers/2607.14431) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.14431)
**Topics:** `inference`, `KV-cache`

### TL;DR

Deposit "verified knowledge" once into a byte-exact **KV-cache artifact**, then graft that KV state into a *fresh* inference context at query time. Weights don't change; the accelerator budget doesn't change; the grafted logit vector is **SHA-256-equal** to a fresh computation, KL divergence zero, argmax agreement 100% across 50 samples — under a pinned deterministic configuration.

### Key idea

Treat the model's KV cache as a **portable, bit-exact knowledge artifact**. Compute the KV state once for a chunk of verified reference material, serialize it byte-exactly, and later re-inject it as the prefix state of a new query. When positional encodings and numerics are pinned, the model's downstream computation is indistinguishable from having re-processed the material.

### Main finding

A frozen 12B model becomes "measurably more capable and dramatically cheaper" via byte-exact KV grafting, with the strongest possible bit-exactness claim: SHA-256 equality of logits, zero KL, 100% argmax agreement.

### Why it matters

Prompt caching, prefix caching, and RAG all approximate this idea; this paper is a maximal statement of the property. Byte-exact grafting sidesteps the reproducibility caveats of cache-with-different-numerics and cleanly separates *knowledge* from *weights*.

## 12. Partition, Prompt, Aggregate

**Authors:** Patrik Wolf, Thomas Kleine Buening, Andreas Krause, Celestine Mendler-Dünner — *ETH Zurich / MPI-IS (Krause / Mendler-Dünner groups)*
**Links:** [arXiv:2607.15277](https://arxiv.org/abs/2607.15277) · [HF](https://huggingface.co/papers/2607.15277) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.15277)
**Topics:** `eval`, `LLM`, `prompting`

### TL;DR

If in-context learning is really conditional inference, LLM outputs should satisfy the **law of total probability**: prior-weighted subpopulation estimates should aggregate to the population marginal. Using binary trees to partition, prompt, and aggregate, the authors show widespread violations across frontier models — and identify a "**macro fallacy**" where fine-grained subpopulation queries beat direct population-level queries.

### Key idea

**Statistical self-consistency as an evaluation criterion.** Recursively partition a population into subpopulations along a tree; prompt the LLM with verbalized descriptions of each leaf; aggregate up via the law of total probability; compare to the direct population-level answer. Any mismatch is a self-consistency violation with no need for ground truth.

### Main finding

Frontier models violate basic self-consistency broadly; fine-grained subpopulation reconstructions align *better* with human reference data than direct population queries — the macro fallacy. Effect persists across tree structures and tasks.

### Why it matters

Reference-free, saturable-only-with-consistent-models — this is a robust new evaluation dimension. Also a practical prompting insight: for population-level estimates, ask subpopulations and aggregate.

## 13. Token Time Continuous Diffusion (TTCD)

**Authors:** Parikshit Bansal, Sujay Sanghavi — *University of Texas at Austin*
**Links:** [arXiv:2607.14106](https://arxiv.org/abs/2607.14106) · [HF](https://huggingface.co/papers/2607.14106) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.14106)
**Topics:** `diffusion`, `LLM`, `generation`

### TL;DR

A **continuous-space** diffusion language model with **per-token time**: some tokens denoise faster than others, and Gaussian noise is mapped deterministically to a final token canvas — no per-step multinomial sampling. Continuous space avoids the parallel-sampling inaccuracy that hurts discrete diffusion at high speedups.

### Key idea

Two moves: (a) operate in continuous embedding space, mapping Gaussian noise → final token canvas deterministically (no per-step sampling), and (b) give each token its own diffusion time — surer tokens progress faster and can influence less-sure tokens. This lets conditional generation exploit differentiated inter-token influence during refinement.

### Main finding

A 160M-parameter TTCD trained on OpenWebText (with self-distillation) is **comparable at high speedups** to similar-size discrete/continuous baselines in unconditional generation and **outperforms in conditional generation**; similar gains on Sudoku.

### Why it matters

Diffusion language models keep almost matching autoregressive on quality; the winning move is parallelism at high speedups. Continuous + per-token time closes the remaining gap on conditional generation, the main use case in practice.

## 14. Rethinking Harness Evolution for Agents

**Authors:** Yike Wang, Huaisheng Zhu, Zhengyu Hu, Yige Yuan, Zhengyu Chen, Shakti Senthil, Hannaneh Hajishirzi, Yulia Tsvetkov, Pradeep Dasigi, Teng Xiao — *Allen Institute for AI / University of Washington*
**Links:** [arXiv:2607.12227](https://arxiv.org/abs/2607.12227) · [HF](https://huggingface.co/papers/2607.12227) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.12227)
**Topics:** `agents`, `eval`

### TL;DR

Critical re-evaluation of **automatic harness evolution** for LLM agents. Existing methods search harness configurations on unit tests and evaluate on the same public benchmark — that's search leakage and no fair budget comparison against simple test-time scaling. This paper matches feedback/inference budgets and holds out tasks — harness evolution then **does not consistently beat plain test-time scaling** and generalizes poorly.

### Key idea

Two evaluation reforms: (a) compare harness-evolution search against **task-level search baselines under matched feedback and inference budgets** to isolate whether the win comes from harness design or from more compute; (b) evaluate on **held-out tasks** to catch overfitting to the search-time benchmark.

### Main finding

On Terminal-Bench 2.1 with GPT-5.4 and Claude Opus 4.6, automatic harness evolution **does not consistently outperform** simple test-time scaling and shows **limited transfer** to held-out tasks.

### Why it matters

A field-level warning label on "auto-evolved agent scaffolds." If the reported gains largely reflect budget mismatch + benchmark overfitting, the recipe most agent-framework papers now use for evaluation is broken. Expect a rewrite of what a "state-of-the-art harness" claim requires.

## 15. GRASP

**Authors:** Varun Gandhi, Jaewook Lee, Shantanu Todmal, Franck Dernoncourt, Ryan Rossi, Zichao Wang, Andrew Lan — *University of Massachusetts Amherst / Adobe Research*
**Links:** [arXiv:2607.10463](https://arxiv.org/abs/2607.10463) · [HF](https://huggingface.co/papers/2607.10463) · [AlphaXiv](https://www.alphaxiv.org/abs/2607.10463)
**Topics:** `agents`, `RAG`, `RL`

### TL;DR

RL-trained agentic RAG policy that learns to coordinate **three retrieval tools at varying granularities**: semantic search, keyword search, and paragraph reading. Rewards balance answer accuracy, grounded reading, complementary search, and turn efficiency.

### Key idea

**Granularity as a first-class action space.** The agent picks *both* which retrieval modality to use *and* what granularity of evidence to load next. Reward composition (accuracy + grounded reading + complementary search + turn efficiency) trains the policy to skim broadly with semantic search, zoom in with paragraph reading, and pin entities with keyword search.

### Main finding

Beats single-step retrieval, prompting-based agentic RAG, and RL-based retrieval baselines on multi-hop QA. Ablations show emergent skimming/scanning behavior aligned with the granularity of the query.

### Why it matters

Agentic RAG has been converging on "call more tools" — GRASP shows that the meaningful axis is *granularity control*, and that a well-shaped reward is enough to learn interpretable skimming/scanning. Combines naturally with SearchOS-style state externalization.
