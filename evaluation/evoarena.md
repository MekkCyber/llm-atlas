# EvoArena
*Depth — benchmark for LLM agents in environments that evolve over time.*

**TL;DR:** Most agent benchmarks freeze the world: the filesystem, the codebase, and the user's preferences are fixed for the entire episode. EvoArena does the opposite — every task is a *sequence of progressive updates* across terminal, software, and social domains, so the agent must track state changes turn-over-turn. Headline result: current frontier agents average just **39.6%** across the suite, exposing memory as the bottleneck for long-horizon deployment.

## What it is

A benchmark suite of multi-turn agent tasks. Each task scripts a sequence of environment updates that the agent must observe, retain, and act on:

- **Terminal domain** — files appear, disappear, get edited; cwd changes; env vars rotate.
- **Software domain** — code is patched between turns; the API surface the agent depended on shifts.
- **Social domain** — user preferences are revealed incrementally and sometimes overwritten.

The eval reports per-task accuracy and **chain-level accuracy** — whether the agent solved a consecutive sequence of dependent subtasks. Chain-level is the more honest number: it punishes agents that get individual turns right but lose track of the through-line.

---

## How it works

### Construction

Each task is authored as a script of state transitions with held-out questions interleaved. Questions probe either the current state or *the diff* between past states. Hidden ground-truth state is generated by replaying the script through a sandboxed environment, so the eval is exact-match against simulator output, not LLM-judged.

### Metrics

- **Per-task accuracy** — fraction of correct answers across all turns.
- **Chain-level accuracy** — fraction of tasks where *every* turn was answered correctly. Drops sharply with task length.

### Baselines

EvoArena reports:
- Frontier closed models with default chat memory → 39.6% average.
- The same models augmented with **EvoMem** (patch-based memory) → +1.5% on the suite, plus transfer gains of +6.1% (GAIA) and +4.8% (LoCoMo).

## Why it matters

- **Static benchmarks overstate agent quality.** A model that aces SWE-bench can still flounder when the codebase shifts mid-task. EvoArena gives the first systematic look at that gap.
- **Memory is now a measurable axis.** Different memory designs (chat buffer, RAG, patch-based) plot on a comparable curve, instead of being lumped together.
- **Cross-benchmark transfer.** EvoMem's gains on GAIA and LoCoMo suggest the memory-evolution axis is upstream of several existing evaluations.

---

## Gotchas & tricks

- **Closed-model API limits matter.** Some scripted update sequences are long enough to fill the context window; truncation policies materially affect scores. Report context length used.
- **Chain-level vs per-task can diverge.** A 90% per-task agent can have <50% chain accuracy on length-10 tasks if errors are roughly independent. Use both.
- **Beware re-running.** The simulator is deterministic but agent rollouts aren't; sample-and-average for headline numbers.
- **Doesn't cover all evolution types.** Schema migrations across days/weeks aren't represented; the benchmark targets within-session evolution.
